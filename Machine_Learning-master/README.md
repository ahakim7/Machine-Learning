# Machine Learning Models (Classification & Prediction)

## Overview
This repository contains multiple machine learning projects focused on classification and prediction tasks using structured datasets. The goal is to apply machine learning techniques to solve real-world problems and understand the full ML pipeline from data preprocessing to model evaluation.

---

## Projects Included

### 1. Wine Quality Prediction (ANN)
- Built an Artificial Neural Network model to predict wine quality based on physicochemical properties.
- Applied data preprocessing and feature scaling.
- Evaluated model performance using accuracy and loss metrics.

---

### 2. Loan Status Prediction (ANN)
- Developed a classification model to predict whether a loan will be approved.
- Handled missing values and categorical data.
- Applied ANN for prediction.

---

### 3. Bank Marketing Prediction
- Predicted customer response to marketing campaigns.
- Used structured datasets and classification techniques.
- Focused on improving prediction performance.

---

### 4. Iris Classification
- Implemented classification models on the Iris dataset.
- Compared performance of different ML approaches.

---

### 5. Sentiment Analysis (Positive/Negative)
- Built a model to classify text sentiment.
- Processed textual data and applied classification techniques.

---

### 6. Suicide Note Detection
- Developed a classification model to detect patterns in text data.
- Focused on NLP-based preprocessing and model training.
